# PR reactions

Retro pulp sci-fi reaction images for pull request and code review events, one folder per event under `images/`. Square 768 x 768 PNGs, compressed for use in PR bodies and comments.

| Event | Folder |
|---|---|
| Review requested | `images/review-requested/` |
| Changes requested | `images/changes-requested/` |
| Fixes pushed | `images/fixes-pushed/` |
| Approved | `images/approved/` |
| Ready to merge | `images/ready-to-merge/` |
| Merged | `images/merged/` |
| Comments provided | `images/comments-only/` |

Link an image by its raw URL:

```
https://raw.githubusercontent.com/IMAHiji/pr-reactions/main/images/approved/01.png
```

All characters and settings are original. No franchise characters, logos, or watermarks.
