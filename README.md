# PR reactions

Retro pulp sci-fi reaction images for pull request and code review events, one folder per event under `images/`. Square 768 x 768 PNGs, compressed for use in PR bodies and comments.

## Gallery set (current)

Since 2026-10-21 PR bodies and review comments draw from `images/gallery/`, quantized copies of the approved pull-request scenes in the private `IMAHiji/practice-gallery` repo (`gallery/pull-requests/`). Wide 16:9 PNGs, one folder per PR state, filenames unchanged from the gallery:

| Event | Folder |
|---|---|
| Review requested | `images/gallery/review-requested/` |
| Feedback posted (comments only) | `images/gallery/feedback-posted/` |
| Changes requested | `images/gallery/changes-requested/` |
| Revisions pushed | `images/gallery/revisions-pushed/` |
| Approved | `images/gallery/approved/` |
